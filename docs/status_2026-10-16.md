## What could move the rank (beyond Oct 17, team research)

1. **Old third-order content without dense legs** (the 0.074 = 31% old tier + joiner).
   Everything the old tier does is Hadamard products of legs (A*P, P*P, A*A) read into D3
   and D21. In a shared basis Q (n x r) these are cubic forms with an r^3 core, which costs
   n r^3 per layer: cheap only at r <~ 150, below the accuracy cliff at r = 224-384. The
   leaders evidently have a representation that avoids this; candidates: (a) a learned
   compact memory (U, Z in R^{n x 32}) distilled from the full chain (note 16 item 6c),
   (b) a role split: old sources feed only the final readout exactly (item 6a), (c) a
   different closure whose third-order state is not per-source.
2. **Accuracy beyond K=3 + memoryless kappa4** (leaders are 25-35% better raw): partial
   fourth-order content (augmented kappa4 trace / (2,1,1) core in compressed form).
3. **Retrain the learned operator on clean labels and on the shipped chain's own
   rollouts** (note 16 items 7, 12): our 1e6-sample labels are ~4x noisier than the error.

## Grader facts (for any future submission)

* every op is an IPC round trip; wall time is compute-bound: keep emulator wall <= ~175 s
  (`scripts/grader_emulator.sh`), rg / rfhub pass at 145-178 s, 215 s fails;
* memory per network: <= ~6.1 GB resident (VmPeak ~7.9 GB) passes, 7.0 GB fails;
* per-result array cap ~135 MB; tuples arrive as lists.
